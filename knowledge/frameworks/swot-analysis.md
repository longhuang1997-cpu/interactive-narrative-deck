# SWOT分析

> **S**trengths · **W**eaknesses · **O**pportunities · **T**hreats

战略分析的经典框架，通过内部优劣势与外部机会威胁的交叉分析，制定战略决策。

---

## 📖 定义

**SWOT分析**是一种战略规划工具，将影响企业的因素分为4个维度：

| 维度 | 英文 | 属性 | 含义 |
|------|------|------|------|
| **优势** | Strengths | 内部/正面 | 相对竞争对手的优势资源和能力 |
| **劣势** | Weaknesses | 内部/负面 | 相对竞争对手的不足之处 |
| **机会** | Opportunities | 外部/正面 | 外部环境带来的有利趋势 |
| **威胁** | Threats | 外部/负面 | 外部环境的不利因素和风险 |

**核心逻辑**：
- **内部因素（S/W）**：可控，通过管理改善
- **外部因素（O/T）**：不可控，需要适应或利用

---

## 🎯 适用场景

### 高频场景
1. **年度/季度战略规划** - 复盘过去、规划未来
2. **新业务进入评估** - 评估是否具备进入条件
3. **竞争态势分析** - 识别相对竞争对手的位置
4. **项目启动分析** - 评估项目可行性

### 典型受众
- **高管/董事会**：战略决策依据
- **管理层**：业务复盘和规划
- **项目团队**：项目启动评估

---

## 🏗 典型结构

### 标准2x2矩阵

```
┌─────────────────┬─────────────────┐
│   Strengths     │   Weaknesses    │
│   优势（内部+）  │   劣势（内部-）  │
│                 │                 │
├─────────────────┼─────────────────┤
│  Opportunities  │    Threats      │
│   机会（外部+）  │   威胁（外部-）  │
│                 │                 │
└─────────────────┴─────────────────┘
```

### 典型汇报页数
- **简版**：1页SWOT矩阵
- **标准版**：3-5页（封面 + SWOT + 战略建议）
- **完整版**：7-10页（背景 + SWOT + 交叉分析 + 行动计划）

## 📐 填写要点

### 优势（Strengths）
**问自己**：相比竞争对手，我们什么做得更好？

**典型角度**：
- 品牌：知名度、美誉度、用户心智
- 产品：功能、体验、技术壁垒
- 资源：资金、人才、渠道、供应链
- 能力：研发、运营、执行力

**示例**：
```yaml
strengths:
  - 品牌知名度行业TOP3，用户心智强
  - 技术团队200+人，AI能力领先
  - 现金流充裕，账上5亿可用资金
  - 供应链响应速度快，交付周期缩短30%
```

### 劣势（Weaknesses）
**问自己**：我们哪些地方落后于竞争对手？

**典型角度**：
- 成本：成本结构不优、利润率低
- 能力：某项能力缺失或薄弱
- 资源：资源投入不足
- 组织：组织效率、流程僵化

**示例**：
```yaml
weaknesses:
  - 国际化团队不足，海外营收占比仅5%
  - 供应链成本高于行业平均15%
  - 产品迭代速度慢，竞争对手2周一版我们1月一版
  - 销售团队流失率高（30%），影响客户关系
```

### 机会（Opportunities）
**问自己**：外部环境哪些趋势对我们有利？

**典型角度**：
- 政策：政策红利、补贴、放松管制
- 技术：新技术成熟、成本下降
- 市场：新兴市场、需求增长、消费升级
- 竞争：竞争对手失误、空白市场

**示例**：
```yaml
opportunities:
  - AI技术成熟，大模型成本下降50%，普及加速
  - 东南亚市场年增长30%，本地化竞争弱
  - 政策鼓励数字化转型，企业采购预算增加
  - 主要竞争对手A裁员20%，客户关系受影响
```

### 威胁（Threats）
**问自己**：外部环境哪些因素可能伤害我们？

**典型角度**：
- 政策：监管收紧、税收提高
- 技术：技术替代、颠覆性创新
- 市场：需求下滑、价格战
- 竞争：新进入者、竞争加剧

**示例**：
```yaml
threats:
  - 监管趋严，数据合规成本提高，部分业务受限
  - 头部竞争对手B融资10亿，准备打价格战
  - 开源替代方案兴起，威胁中低端市场
  - 宏观经济下行，客户预算削减20%
```

## ⚠️ 常见误区

### ❌ 误区1：优势=能力，劣势=缺点
**错误**：
- 优势：产品功能多
- 劣势：团队规模小

**正确**：优势/劣势是**相对竞争对手**的
- 优势：产品功能比竞争对手多20%，覆盖更多场景
- 劣势：团队规模仅竞争对手1/3，响应速度受限

### ❌ 误区2：机会=目标，威胁=问题
**错误**：
- 机会：营收增长50%
- 威胁：产品有Bug

**正确**：机会/威胁是**外部环境因素**
- 机会：市场需求增长50%，行业整体扩张
- 威胁：竞争对手降价30%，引发价格战

### ❌ 误区3：只列现象，不讲影响
**错误**：
- 威胁：监管收紧

**正确**：
- 威胁：数据监管收紧，合规成本提高200万/年，部分变现模式受限

## 🔗 相关方法论

### 前置分析工具（用于收集SWOT素材）
- **PESTEL分析** - 宏观环境扫描（政治/经济/社会/技术/环境/法律）
- **Porter五力模型** - 行业竞争分析
- **价值链分析** - 内部能力拆解

### 后续决策工具（基于SWOT结论）
- **TOWS矩阵** - SWOT交叉分析，推导战略方向
  - SO策略：利用优势抓住机会
  - ST策略：利用优势化解威胁
  - WO策略：弥补劣势抓住机会
  - WT策略：规避劣势和威胁
- **安索夫矩阵** - 增长战略选择
- **BCG矩阵** - 资源配置决策

## 📚 案例库

### 案例1：某SaaS公司Q3复盘（向董事会）

**背景**：云办公SaaS公司，Q3营收同比+60%，准备融资B轮

```yaml
strengths:
  - 产品易用性NPS 85分，行业第一
  - 大客户续费率98%，远超行业平均75%
  - 技术栈稳定，7x24小时可用率99.9%
  - 团队执行力强，Q3目标100%达成

weaknesses:
  - 国际化能力弱，海外营收占比仅3%
  - 中小客户获客成本高，CAC/LTV=0.8（不健康）
  - 产品线单一，仅办公协作，缺乏生态
  - 销售团队新人多，成单周期长

opportunities:
  - 远程办公需求持续增长，市场年复合30%
  - 大模型技术成熟，AI+办公成为趋势
  - 竞争对手A出现数据泄露丑闻，客户流失
  - 政策鼓励企业数字化，采购预算增加

threats:
  - 巨头入场（微软/腾讯），价格战风险
  - 开源替代方案成熟，威胁中小客户
  - 数据合规要求提高，合规成本+200万/年
  - 宏观经济不确定性，客户砍预算
```

**战略结论**：
- SO策略：用产品易用性+AI技术，抢竞争对手A的大客户
- ST策略：强化数据安全认证，对抗巨头竞争
- WO策略：拓展产品线（AI助手），降低获客成本
- WT策略：暂缓国际化，聚焦国内大客户

### 案例2：某零售品牌新市场进入评估（向CEO）

**背景**：国内时尚品牌，考虑进入东南亚市场

```yaml
strengths:
  - 国内品牌知名度高，年轻人心智强
  - 供应链柔性，小单快反，15天交付
  - 线上运营能力强，直播/社交电商成熟
  - 现金流健康，可投入5000万试水

weaknesses:
  - 无海外团队，本地化经验为0
  - 品牌溢价能力弱，依赖性价比
  - 售后体系未覆盖海外
  - 跨境物流成本高，侵蚀利润

opportunities:
  - 东南亚市场年增长40%，中产阶级崛起
  - 本地竞争分散，无强势品牌
  - 跨境电商平台成熟（Shopee/Lazada）
  - 中国文化影响力上升，年轻人喜欢中国品牌

threats:
  - 关税/汇率波动风险
  - Zara/Uniqlo等快时尚巨头已深耕
  - 本地消费习惯不确定，试错成本高
  - 疫情反复，物流不稳定
```

**战略结论**：
- 机会大于威胁，但需轻量级试水
- 先选1个国家（泰国/越南），投入1000万测试
- 走线上平台（Shopee），避免重资产开店
- 6个月后复盘，决定是否扩张

# 技术分享示例 · Tech Talk Demo

覆盖**故事-共鸣型**叙事框架，适合技术分享/内部培训/经验传递场景。

## 包含的Block类型
- `hero` 封面
- `bullets` 背景交代（渐进揭示）
- `compare` 新旧方案对比
- `metric` 效果量化
- `bullets` 踩坑总结（渐进）
- `quote` 收尾金句

## 运行
双击 `index.html` → F11全屏 → 左右键翻页 → 空格键逐条揭示踩坑内容

## 定制
- 换配色：改 `deck.js` 顶部 `theme` 里的 `blue/gold/bg`
- 换内容：改每页 `blocks` 里的文字，结构不变

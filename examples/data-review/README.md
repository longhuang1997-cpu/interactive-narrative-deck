# 数据复盘示例 · Data Review Demo

覆盖**数据-洞察型**叙事框架，适合季报/年报/业务复盘场景。

## 包含的Block类型
- `hero` 封面 + 章节标题
- `metric` 4个KPI数字滚动
- `chart` 折线图双系列对比
- `bullets` 渐进揭示洞察要点
- `timeline` 季度行动路线图
- `quote` 金句收尾

## 运行
双击 `index.html` → F11全屏 → 左右键翻页 → 空格渐进

## 修改数据
打开 `deck.js`，找到 `metric` 的 `items` 和 `chart` 的 `data.datasets`，替换为你的真实数据。

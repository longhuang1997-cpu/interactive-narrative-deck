## 如何截图

1. 启动本地服务器：`python -m http.server 8080`
2. 访问：`http://localhost:8080/examples/all-professional-blocks/`
3. 切换到相应页面（方向键→）
4. 按F11全屏
5. 截图工具（Windows: Win+Shift+S，Mac: Cmd+Shift+4）
6. 保存为PNG格式，命名按上述规范
